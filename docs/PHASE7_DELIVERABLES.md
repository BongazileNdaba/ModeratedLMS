## Deployment qualification
The intended deployment is an offline C++ application using SQLite on a school computer/local network as described by the case study. The present executable is a console application. Submission records store a file path; they do not yet constitute a secure managed upload/storage facility. No multi-workstation network protocol or 800-student load-test evidence is established by these documents. The installation guide must be reconciled with the exact interactive build and must not describe unimplemented facilities as available.
